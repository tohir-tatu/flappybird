# Flappy Bird — 2D sahna (Unity 6)

"Mobile game programming" fanidan 1-amaliy ish: Flappy Bird o'yini uchun 2D sahna va sahnadan tashqari obyektlar (prefablar).

- Unity 6000.6.2f1, Universal 2D (URP) shabloni
- Sahna: `Assets/Scenes/SampleScene.unity`

## Sahna tarkibi
- **Environment**: Sky (osmon), Sun (quyosh), Clouds (4 ta bulut), Hills (tepaliklar), Ground (yer)
- **Gameplay**: Bird (qush), Pipes (3 ta quvur juftligi)

## Sahnadan tashqari obyektlar (prefablar)
- `Assets/Prefabs/Bird.prefab` — qush
- `Assets/Prefabs/Pipe.prefab` — yuqori va pastki quvur (Top, TopCap, Bottom, BottomCap)
- `Assets/Prefabs/Cloud.prefab` — bulut

Rasmlar: `Assets/Sprites/`

> Ushbu loyiha Claude (AI yordamchi) yordamida tayyorlangan.
